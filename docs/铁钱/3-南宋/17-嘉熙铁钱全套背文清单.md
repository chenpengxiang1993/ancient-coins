# 嘉熙铁钱｜纯文本完整背文存档版（直接复制记事本）
> 嘉熙（1237‑1240）；两淮钱监全部废罢，**无两淮春、汉、同、松流通铁钱**；铁钱全部四川邛州惠民监铸造；沿用端平体系：监名+纪值+方位；铁母/铁范铜为铜质，不属于流通铁钱。
> 说明：嘉熙元宝无铁钱；嘉熙重宝只有铜钱；铁钱仅嘉熙通宝，分折五、折十；蒙元战事吃紧，铸虚值大钱。

# 关键备注（纯文本）
1.嘉熙时期两淮钱监彻底停铸铁钱，所有春汉同松背文全部臆造。
2.铁钱只有嘉熙通宝折五、折十；元宝、重宝无铁钱。
3.折五为惠伍+东/西‑上中下；折十为十+惠/东/西+炉次；无定伍系列，定伍止于端平。
4.嘉熙折十铁钱存世稀少，市面绝大多数实物为仿品、改刻。
5.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
6.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“嘉熙铁母”为仿品。
