# 关键备注（纯文本）
1.绍熙年号仅五年，纪年只到元‑五，出现六及以上为臆造。
2.“光二”是定城监早期记监，之后全部改“定”，没有光元、光三、光四、光五真品。
3.春山、定山属于大名誉试铸，市面绝大多数为改刻仿品。
4.折三铁钱四川铸造，只有月孕双星，不使用春汉同定这套纪监。
5.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
6.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“绍熙铁母”为仿品。
