# 关键备注（纯文本）
1.圣宋重宝仅南宋嘉定元年四川利州监铸折五铁钱，真品背只有**利壹伍**，属于川铁名誉品，市面绝大多数实物为仿品、改刻。
2.不使用两淮春汉同松纪监，也无邛、西、惠等邛州监背文。
3.北宋圣宋元宝、圣宋通宝不属于这套南宋四川铁钱序列，不要混淆。
4.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
5.铁母全部铜质，铁钱本身不是铁母；市面“圣宋重宝铁母”几乎全部仿品。
