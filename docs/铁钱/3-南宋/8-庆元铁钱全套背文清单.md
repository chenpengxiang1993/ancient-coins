# 庆元铁钱｜纯文本完整背文存档版（直接复制记事本）
> 庆元（1195‑1200）；庆元通宝铁钱：两淮荆湖钱监（春=蕲春监、汉=汉阳监、同=同安监）；庆元元宝铁钱：四川巩州惠民监；铁母/铁范铜为铜质，不属于流通铁钱。
> 说明：年号仅六年，出现背“七”，为钱监提前预铸次年钱币，属于真品体系。

# 关键备注（纯文本）
1.庆元年号仅六年，背“七”为钱监预铸，属于真品版式。
2.庆元通宝使用春、汉、同纪监纪年；**庆元元宝只用川字系统，二者不可混淆**。
3.背永属于大名誉试铸，民间市场绝大多数为改刻仿品。
4.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
5.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“庆元铁母”为仿品。
