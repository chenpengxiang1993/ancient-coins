# 隆兴铁钱｜纯文本完整背文存档版（直接复制记事本）
> 隆兴（1163‑1164）；**两淮春、汉、同、松钱监尚未设立，无两淮纪监体系**；铁钱全部四川铸造（邛州惠民监、嘉州丰远监）；铁母/铁范铜为铜质，不属于流通铁钱。
> 说明：年号仅二年；**无数字纪年背文**；纪监+纪年制度淳熙七年才启用；隆兴通宝铁钱存世稀少。

# 关键备注（纯文本）
1.隆兴时期两淮铁钱监还未建立，**铁钱只有四川铸造，全部光背，不存在春汉同松**。
2.没有任何数字纪年背文，纪监+纪年制度始于淳熙七年。
3.隆兴通宝铁钱仅折二，小平通宝无流通真品，市面绝大多数为仿品。
4.隆兴铸期仅两年，整体铁钱存世偏少。
5.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
6.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“隆兴铁母”为仿品。
