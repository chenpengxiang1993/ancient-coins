# 关键备注（纯文本）
1.纯熙仅同安监少量试铸背上同小平铁钱，其余钱监未开工即接停铸诏令，没有春、汉、松、利、邛体系的纯熙铁钱。
2.无折二、折三，无通宝，所有折二折三纯熙铁钱均为仿品或改刻。
3.存世极罕，市面流通所见几乎全部仿改刻。
4.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
5.铁母全部铜质，铁钱本身不是铁母；市面“纯熙铁母”几乎全仿品。
