# 关键备注（纯文本）
1.开禧年号仅三年，两淮铁钱纪年只到元‑三，春四、汉四、同四铁钱为臆造。
2.开禧元宝**只有折三铁钱，无小平、折二流通铁钱**；真品背文为利六十、利六一，属于少见名誉品，市面仿品极多。
3.利六十、利六一为利州绍兴监炉次编号，不是纪年数字。
4.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
5.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“开禧铁母”为仿品。
