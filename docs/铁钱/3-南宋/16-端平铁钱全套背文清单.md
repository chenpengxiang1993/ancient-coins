# 关键备注（纯文本）
1.两淮体系极度衰败，端平通宝小平铁钱真品只有**春元**，其余春二及以后全部臆造。
2.四川折五铁钱分两大组：通宝惠伍系列；元宝定伍系列；背文为监名+纪值+方位（东/西/北‑上中下）。
3.端平元宝折十铁钱真品仅**利折十**，属于大名誉品，市面绝大多数实物为仿改刻。
4.端平重宝只有铜钱，不存在铁钱。
5.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
6.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“端平铁母”为仿品。
