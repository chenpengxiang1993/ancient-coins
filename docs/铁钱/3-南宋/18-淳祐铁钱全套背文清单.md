# 关键备注（纯文本）
1.淳祐时期两淮铁钱监全部消亡，所有春汉同松背文全部臆造。
2.端平、嘉熙那套「监名+伍+方位（上中下）」背文体系到此终结，淳祐铁钱不再使用。
3.流通主体只有**淳祐通宝背当百铁钱**；背庆当二十文属于顶级大珍，市面所见绝大多数为仿改刻。
4.折二、折五、重宝铁钱全部属于试铸，没有批量行用。
5.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
6.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“淳祐铁母”均为仿品。
