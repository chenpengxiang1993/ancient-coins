# 宝庆铁钱｜纯文本完整背文存档版（直接复制记事本）
> 宝庆（1225‑1227）；宝庆元宝仅铸铁钱，铜钱极罕；两淮监：汉=汉阳监；四川监：定=嘉州丰远监、惠=邛州惠民监；蕲春、同安监此时基本废罢；铁母/铁范铜为铜质，不属于流通铁钱。
> 说明：宝庆元宝铸期极短，主要铸于宝庆元年正月‑七月，之后行用大宋元宝；不再使用旧的春、同、松纪监；无数字纪年体系。

# 关键备注（纯文本）
1.两淮旧春、同、松监宝庆时期已经废停，宝庆铁钱无春、同、松背文。
2.小平只有汉月；折二只有定二；折三：定三、惠三、惠正三。
3.宝庆无常规铜钱，宝庆元宝只见铁钱；背汉月铁母为顶级大珍，市面所见几乎全仿。
4.四川宝庆铁钱使用定、惠，不再沿用前期利、邛记监。
5.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
6.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“宝庆铁母”为仿品。
