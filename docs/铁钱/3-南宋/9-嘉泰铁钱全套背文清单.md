# 关键备注（纯文本）
1.嘉泰两淮铁钱纪年只到元‑三，**春四、汉四、同四铁钱为臆造**；铜钱有背四，不要混淆。
2.嘉泰元宝小平、折二两淮铁钱**只有元年（春元、汉元、同元）**，无二、三纪年。
3.四川嘉泰元宝折三铁钱真品仅**川二卅九**，属于大名誉品，市面绝大多数为仿品。
4.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
5.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“嘉泰铁母”为仿品。
