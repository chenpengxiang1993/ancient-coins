# 绍兴铁钱｜纯文本完整背文存档版（直接复制记事本）
> 绍兴（1131‑1162）；**两淮地区无官铸流通铁钱**；铁钱全部出自四川：邛州惠民监、嘉州丰远监；利州绍兴监后期恢复铸钱；铁母/铁范铜为铜质，不属于流通铁钱。
> 说明：绍兴前期长期罢铸铁钱；绍兴22‑31年恢复小平铁钱；**尚未诞生春、汉、同、松纪监+纪年体系**；无数字纪年背文；折二、折三铁钱均为试铸，无批量流通。

# 关键备注（纯文本）
1.绍兴年间**两淮钱监尚未开办铁钱铸造**，春汉同松这套两淮纪监系统乾道才出现，绍兴铁钱不可能出现。
2.仅小平元宝、通宝有批量流通铁钱，全部光背；折二及以上都是试铸，民间市场所见绝大多数为仿品。
3.背邛、背利为乾道之后四川铁钱纪监，绍兴铁钱不存在此类背文。
4.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
5.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“绍兴铁母”为仿品。
