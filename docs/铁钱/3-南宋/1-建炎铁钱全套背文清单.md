# 关键备注（纯文本）
1.建炎铁钱**没有春汉同松这套两淮纪监系统**，两淮铁钱监是乾道之后才逐步恢复设立。
2.流通铁钱只有小平；折二、折三铁钱全部属于试铸，市面所见绝大多数为仿品。
3.小平铁钱真品背仅两种：光背、背上川。
4.邛州惠民监建炎二年罢铸，铸期很短，建炎铁钱总体存世不多。
5.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
6.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“建炎铁母”为仿品。
