# 关键备注（纯文本）
1.永隆通宝铁钱全部折十，**背文必须带“闽”字**，无闽字的永隆通宝铁钱必伪。
2.铸期很短，一钱一范陶范铸造，存世总量不多；市面流通所见绝大多数实物为仿品、改刻。
3.典型尺寸：直径36‑41mm，重量15‑33g；同版铜钱、铅钱为大珍，民间极罕。
4.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
5.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“永隆铁母”均为仿品。
