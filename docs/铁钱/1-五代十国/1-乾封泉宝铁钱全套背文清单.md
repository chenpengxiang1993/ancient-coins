# 关键备注（纯文本）
1.楚乾封泉宝铁钱真品背仅四种：**天、策、天府、天策**；背天府、背天策属于大罕品，市面所见绝大多数为仿改刻。
2.只有折十大型铁钱，无小平折二折三；唐高宗乾封泉宝只有铜钱，没有铁钱，注意区分两个时代。
3.湖南本地出土，钱体厚重，常见直径33‑42mm，重量20‑33g。
4.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
5.铁母全部铜质，铁钱本身不是铁母；市面绝大多数“乾封泉宝铁母”均为仿品。
