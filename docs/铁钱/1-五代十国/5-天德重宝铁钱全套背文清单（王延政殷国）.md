# 天德重宝、天德通宝铁钱｜纯文本完整背文存档版（直接复制记事本）
> 天德（943‑945，闽·王延政，国号殷）；建州铸造；大钱一当百；铁母/铁范铜为铜质，不属于流通铁钱。
> 说明：天德重宝背殷；天德通宝铁钱光背；二者均折十；铸期极短，存世极罕，市面实物绝大多数为仿品、改刻。

# 关键备注（纯文本）
1.天德重宝铁钱背**只能是殷**；天德通宝铁钱**只能光背**，二者不可混淆；天德通宝没有背殷铁钱。
2.全部为折十大型铁钱，无小平、折二、折三流通铁钱。
3.铸期短，战乱随即亡国，铁钱极易锈蚀，完整真品非常稀少，流通市场所见几乎全仿改刻。
4.铁钱禁止酸洗、过碳酸钠、打磨；仅软毛刷清扫浮土，密封盒+干燥剂保存。
5.铁母全部铜质，铁钱本身不是铁母；市面“天德铁母”几乎全仿品。
