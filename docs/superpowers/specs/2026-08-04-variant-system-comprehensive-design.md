# 版别体系穷尽收录 — 技术设计文档

日期：2026-08-04
状态：已批准（用户确认：穷尽收录、清单驱动审计、逐版别精确标注、描述须准确详尽便于学习）

## 1. 需求概述

- **目标**：将全库 20 朝代 506 枚钱币（`data/dynasties/0-19.json`）的 `variantsTable` 从「代表性版别」提升为「穷尽权威记载版别」，且每条描述**准确详尽、具备学习价值**。
- **背景**：上一轮深化（2026-08-03）已解决「描述过短/泛语」（弱描述归零），但版别**体系完整度**不足——即未穷尽权威文献记载的版别。已知缺口示例：
  - 开元通宝缺容弱、尨字、背周等版别；
  - 会昌开元仅 8 种背字（权威记载 23 种）；
  - 崇祯通宝缺京版大样、户五/工五等纪局纪值版别。
- **约束**：AGENTS.md 强制——逐朝代按序（0→19）、逐钱币按序、禁用批量脚本改数据、每朝代完成后 `pnpm run validate`、权威来源核实、禁止编造不存在的钱币或版别。

### 已确认决策
1. **穷尽收录**：每枚钱币穷尽收录权威文献有明确记载的所有主要版别；存世极罕者保留少量行（穷尽 ≠ 凑数）。
2. **清单驱动审计**：新建只读脚本 `scripts/audit-variant-completeness.mjs`，内置权威版别清单，驱动并验证完成度。
3. **逐版别精确标注**：新增版别逐行标注马定祥十级制品级 + 市场参考价区间，价格统一「仅供参考」。
4. **学习导向描述**：每条版别描述须「可辨识」——说明核心鉴别特征，让人凭描述能认出该版并理解与普通版的差异。

## 2. 方案设计

### 2.1 新增审计脚本 `scripts/audit-variant-completeness.mjs`

**只读审计**，不修改任何数据文件。

- 内置 `VARIANT_STANDARD`：按 `{dynastyIndex → coinName → [期望版别关键词数组]}` 组织。
- **匹配逻辑**：每个期望关键词须在至少一行版别名中出现（容忍「背"京"版（京师）」「容弱」等命名变体），未匹配即报「缺失」；数据有而清单无的报「多余」供人工复核（不自动删除，用于发现既有冗余/重复行）。
- **输出**：逐币缺失/多余清单 + 每朝代汇总；`归零` 即该朝代达标。
- **清单维护**：清单与数据修改同步增长；每朝代开工前先为该朝代钱币梳理并写入清单。

### 2.2 执行模型（AGENTS.md §2 顺序）

每个朝代（0→19）内：

```
a. 梳理该朝代权威版别清单（写入 VARIANT_STANDARD）
   —— 依据华光普《中国古钱目录》《中国钱币大辞典》《中国古钱谱》《历代古钱图说》
b. 逐枚 Edit 扩充 variantsTable（严禁批量脚本/sed/jq/Node/Edit replace_all）
c. pnpm run validate + node scripts/audit-variant-completeness.mjs → 归零
d. 修复审计「多余」项暴露的冗余/重复行（如崇祯「跑马版/奔马版」重复需合并）
e. 逐朝代 git commit
```

### 2.3 版别行结构与描述规范（学习导向核心）

**行结构**：`{ variant, description, grade, priceRange, notes }`，schema 不变；同名版别多品级时用相邻同名行，前端自动分组（如「容弱版[美品]/容弱版[普品]」）。

**版别行顺序**：形制 → 书体 → 背文 → 特殊品（鎏金/合背/铁钱等）。

**description 描述规范**（四条，逐条体现「可辨识、可学习」）：
1. **面文与读法**：面文原文 + 书体 + 旋读/直读（与既有 featuresGroup 口径一致）。
2. **鉴别特征**：指出该版别的核心辨识点——笔画形态、字口结构、穿廓形制、背文/纹饰位置与写法等；有对比对象的与普通版对比（如「容弱：'通'字'甬'部笔画纤细软弱，与正样对比一目了然」）。
3. **尺寸重量**：直径、重量等可量化的参数。
4. **背景与存世**：铸局/纪年/存世量级，简短交代。

**grade/priceRange 规范**：
- 品级：马定祥十级制（如「七级（甚少）」「八级（较多）」），与现有数据风格一致。
- 价格：市场参考价区间，稀缺度高的高、常见则低；价格统一「仅供参考」。
- notes：铸局/版别来源/简称等补充，保持简短。

### 2.4 数据纪律

- **禁止编造**：仅收录权威文献有明确记载的版别；不确定或有争议的版别不加；存世极罕币（如咸通玄宝）保留权威记载的少量版别行，不凑数。
- **既有行处理**：保留有效的既有行并补全描述；删除/合并重复行（审计「多余」项驱动，人工确认后处理）。
- **读法口径**：沿用既有旋读/直读分类（audit-features.mjs 已覆盖，不得回归）。

## 3. 影响范围

- **新增文件**：`scripts/audit-variant-completeness.mjs`（只读审计）
- **修改文件**：`data/dynasties/0-19.json`（全 20 个，逐朝代推进）
- **不改动**：前端组件、类型定义（`VariantTableRow`）、构建管线、既有审计脚本

```

P1: 逐朝代推进（每朝代内按 2.2 执行）
    0 先秦 → 1 秦 → 2 汉 → 3 三国 → 4 两晋十六国 → 5 南朝 → 6 北朝

    → 10 北宋 → 11 南宋 → 12 辽 → 13 金 → 14 西夏 → 15 元
```

体量说明：穷尽收录 506 枚 + 逐条手工编辑，预计多会话完成；每朝代独立提交、可中断续做。
